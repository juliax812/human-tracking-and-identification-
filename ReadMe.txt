1. frag_custom_dataset:
	Contains all tracklet fragments generated using YoloX nano, tiny, small on a custom dataset.
2. frag_open_benchmark:
	Contains all tracklet fragments generated using YoloX nano, tiny, small on selected MOT series.
3. ncnn_detection_weights:
	Contains 3 different neural network parameters and weights to be deployed in NCNN. (nano, tiny, small)
4. custom_dataset:
	Contains all custom footages shoot onfield. (Original version and Line version)
5. PC_1.3:
	Actual android application for pedestrian count in real-time.
6. EXP1_DetTrk.zip:
	Experiment 1 folder, contains codes for both detection, tracking, and testing purpose.
7. EXP2_Filter.zip:
	Experiment 2 folder, contains codes, experiment, evaluations on 4 filtering algorithms.
8. documentations:
	Contain all necessary documentations, including:
	a) Pedestrian_Count.ipynb:
		Colab notebooks for EXP1 and EXP2.
	b) Pedestrian Count Mobile Implementation.pdf:
		Project report.
	c) ReadMe.txt
		Instructions about folder structure.
9. Others:
